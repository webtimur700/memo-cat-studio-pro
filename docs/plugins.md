# Плагины: эффекты в готовых клипах

Загрузчик (`plugins/loader.py`) при запуске приложения читает папки из `plugins.enabled_dirs` (по умолчанию `plugins/` и
`plugins/examples/`): каждая подпапка с `plugin.py`, экспортирующим объект `PLUGIN`, регистрирует эффекты в `PluginRegistry`.
Сломанный плагин пропускается, остальные грузятся. Новые плагины подхватываются после перезапуска.

## Как выбрать эффект

Настройки → «Эффекты (плагины)»: галочки по загруженным эффектам, порядок — как в списке. Выбор хранится в базе
(`plugins.enabled_effects`). Выбранный эффект, плагина которого больше нет, показывается как «(плагин не найден)», а не пропадает молча;
в лог пишется предупреждение, клип собирается без него. Имена применённых эффектов пишутся в JSON клипа (`effects`).

## Что происходит при экспорте

`export/frame_effects.py`: кадры базового видеоряда (после кадрирования и масштаба) читает OpenCV, они проходят эффекты по порядку
(`кадр BGR uint8 H×W×3 -> кадр BGR`) и уходят в ffmpeg по трубе, звук копируется. Затем накладываются субтитры и оверлеи
(плашка, логотип, Subscribe): **брендинг и текст эффектом не тонируются**.
Эффект, бросивший исключение или вернувший кадр другой формы/типа, отключается для этого клипа (в лог), клип собирается дальше.

Эффекты не выбраны → проход не запускается вообще, экспорт идёт по прежнему пути (тест
`test_without_effects_there_is_no_extra_pass...` падает, если проход всё же запустился).

## Проверка на реальном видео (90 с из `myvideo.mp4`, 2 клипа по 15–18 с, 1080×1920)

Слева без эффекта, справа `vintage_sepia` (`docs/img/plugin_sepia.png`): кадр тонирован (доля пикселей R ≥ G ≥ B 0.99 против 0.90,
средний цвет области видео (152, 111, 86) → (138, 130, 107)), красная кнопка, фиолетовый логотип и плашка сохранили цвета.

Цена: экспорт клипа 37.5 и 34.2 с без эффектов против 56.0 и 49.9 с с сепией (+18 и +16 с на клип: покадровая обработка
в Python на 1080×1920).

## Как написать свой эффект

Скопировать `plugins/examples/example_effect_plugin/` в `plugins/<имя>/`, изменить `metadata()`/`register()` и функцию эффекта.
