# Memo Cat AI Studio Pro

Локальная (офлайн) AI-студия для автоматической нарезки вирусных YouTube
Shorts из видео с животными — детекция интересных моментов, автокадрирование
в 9:16 со слежением за животным, вшитые субтитры с подсветкой слова,
анимированная рекламная плашка, генерация заголовков/описаний/хештегов через
локальную LLM (LM Studio).

Собирается под конкретное железо: **AMD Ryzen 7 8845HS / Radeon 780M / 32 GB
RAM / Bazzite Linux (Fedora Atomic), GNOME**. Работает полностью офлайн после
установки, кроме первоначальной загрузки моделей.

## Статус реализации

Проект строится последовательно по шагам архитектуры. На данный момент
реализованы, протестированы вживую и подтверждены реальными прогонами
(включая сквозные интеграционные тесты, генерирующие настоящие видеофайлы):

| Модуль | Статус |
|---|---|
| Архитектура / структура / конфигурация | ✅ |
| UI (PySide6) | ✅ |
| Video Engine (ingestion, FFmpeg, PySceneDetect, frame extraction) | ✅ (детекция сцен не протестирована вживую — см. `video/scene_detector.py`) |
| AI Engine (ComputeBackend, YOLO11, tracker, motion heuristics, MediaPipe, smart crop) | ✅ (YOLO-инференс не протестирован на реальных весах — см. `vision/yolo_detector.py`) |

или GPU в среде разработки), задокументированы прямо в docstring
соответствующих модулей.

## Быстрый старт

См. [INSTALL.md](INSTALL.md) — пошаговая установка под Bazzite/Distrobox с
диагностикой GPU-backend'а и troubleshooting-таблицей.

Коротко:
```bash
git clone <repo> memo-cat-studio-pro && cd memo-cat-studio-pro
./scripts/install.sh
source .venv/bin/activate
python -m ui.main_window
```

## Архитектура

Clean Architecture: `core/` (доменные сущности и интерфейсы, ничего не знает
о Qt/FFmpeg/ONNX) → `video/`, `vision/`, `audio/`, `subtitles/`, `llm/`,
`effects/`, `animation/`, `export/` (Infrastructure, реализуют интерфейсы из
`core/`) → `ui/` (Presentation, PySide6). DI собирается вручную через
конструкторы (без тяжёлого DI-фреймворка — проект достаточно компактен, чтобы
это не создавало проблем).

Подробности решений и их обоснование — в истории разработки проекта
(Шаги 1-14, см. переписку с ассистентом либо `CHANGELOG.md`).

## Честные ограничения

- **ROCm/Vulkan на Radeon 780M**: не гарантированы стандартной сборкой
  `onnxruntime` — приложение честно проверяет реальную доступность в рантайме
  и откатывается на CPU, не притворяясь, что GPU используется, если это не так.
  См. `config/compute_profiles.yaml` и `vision/compute_backend.py`.
- **"Эмоции животных"**: реализованы как эвристики по траектории движения
  (`vision/pose_motion_analyzer.py`), не как ML-модель распознавания эмоций —
  такой общедоступной модели с приемлемой точностью не существует.
- **"Морда животного" для collision detection**: геометрическая эвристика
  (верхняя часть bbox животного), не отдельная ML-модель — см.
  `vision/mediapipe_face.py`.
- **WebM/VP9 не используется для альфа-канала**: в процессе разработки
  обнаружено, что используемая сборка ffmpeg заявляет поддержку
  `yuva420p` в `libvpx-vp9`, но реально теряет альфа-канал при кодировании —
  используется `qtrle`/MOV, подтверждено round-trip тестом. См.
  `export/export_service.py`.
