# Фоновая музыка

Положите сюда треки (mp3, wav, ogg, m4a, flac, aac, opus) **без авторских ограничений** — свою музыку,
сгенерированную ИИ или с явной свободной лицензией. Чужой трек даст претензию Content ID на YouTube,
поэтому в репозиторий музыка не добавляется (`assets/music/*` в `.gitignore`).

Клип получает один трек: выбор стабилен по имени клипа, предпочитается трек не короче клипа. Папка пуста —
клипы собираются без музыки, в логе строка «Музыка не добавлена». Включение и громкость — в настройках.
